# Banner：匯流

## 視覺方向

留白讓觀看者先辨識名字，再沿著線條觀察秩序如何形成。寬幅畫面容納探索的距離，文字集中在左側，細密的生成線條在右側展開。

底色採暖紙白，深綠提供穩定的結構，陶土橘標出另一組路徑。兩種顏色共用同一個場域，對應兩套開發工具沿用一份規範的專案特性。

線條起初保有各自的幅度與相位，經過三組括號式檢查點後，逐步收斂。檢查點刻意只畫邊界，讓視線能繼續追蹤每一條路徑。它們象徵釐清、建置與驗證，並非完整九階段流程圖。

字體、間距與線寬以縮小後的閱讀為準。標題使用 Instrument Sans，標記使用 Geist Mono；細節透過兩倍解析度繪製後縮圖保留。第二次檢視重點是留白、對齊與線條密度，不以新增裝飾填滿畫面。

## 生成方式

固定種子 913 產生每條路徑的相位、頻率、幅度與濃度。每次以相同輸入繪製，都會得到相同構圖；隨機性只影響受限制的變化。

116 條路徑各取樣 621 個點。橫向位置代表進程，垂直位置由逐漸收窄的通道、共同漂移與個別波動相加而成。

通道寬度隨進程減少，個別波動以較快速度衰減。這使路徑在起點仍能探索，接近終點時保持可辨識的間距，呈現共同規範帶來的收斂。

設計採用使用者提供的 canvas-design 排版與 canvas 方法，以及 algorithmic-art 的固定種子、參數化路徑與受控變化。本次交付是 README 靜態 banner，因此使用 Pillow 輸出 PNG；附件中的 p5.js 互動檢視器與品牌介面不屬於這次輸出範圍。未將附件內的示範口吻視為使用者的新要求。

## 重新繪製

成品為 **2520 × 1080 px（21:9）**。需要 Python 3.11+、Pillow，以及使用者提供的 `canvas-design.zip`。字型從 ZIP 讀取，不需要安裝到系統。

在 repository 根目錄執行：

```bash
python3 .tmpl.docs/assets/banner/render.py --font-archive /path/to/canvas-design.zip
```

需要另存檔案時使用 `--output /path/to/banner.png`。ZIP 未納入 repository；其中字型的 OFL 授權由原始 ZIP 一併提供。生成器保留於此目錄，預設初始化會隨範本素材一起移除。
