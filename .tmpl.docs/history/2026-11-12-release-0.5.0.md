## 過程中的偏差

- **commit skill 的版本**：AGENTS.md 要求使用專案內的 `tw-emoji-commit`，但一開始載入的是使用者層級的同名 skill。兩份的 sanitizer 位元組相同、type 對照表相同，差別只在把草稿交給 sanitizer 的方式。發現時有兩個未 push 的 commit 用了表上沒有的 `🔖`、`🧪 test`，已合併為一個 `🏗️ build` commit，並照專案版流程重新產生 message。
- **CI 等待方式**：開啟 #20 的 Auto-fix 第一次被 auto mode 權限檢查擋下，使用者明確要求後才開啟；repo 不允許 GitHub auto-merge。依環境規則不自行輪詢 PR CI，改由使用者告知全綠後再合併。
- **PR 標題**：`🏗️` 在 GitHub PR 標題顯示為 `🏗`，少了 variation selector；commit message 本身保留完整字元。
