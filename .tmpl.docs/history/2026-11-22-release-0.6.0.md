## 過程中的偏差

- **commit 落在 main**：#24 的第一個 commit 一度直接提交在本機 `main`。當時尚未 push，所以先開工作分支把 commit 帶過去，再把本機 `main` 移回 `origin/main`，遠端沒有受影響。
- **commit skill 的版本**：第一次呼叫載入的是使用者層級的同名 `tw-emoji-commit`。實際 commit 前改讀專案版的 SKILL.md，並使用專案版的 sanitizer。
- **PR 標題**：`🏗️` 在 GitHub PR 標題顯示為 `🏗`，與 v0.5.0 相同；commit message 本身保留完整字元。
